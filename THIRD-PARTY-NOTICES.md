# Уведомления о сторонних компонентах

Этот проект включает в себя сторонние компоненты, распространяемые на
условиях собственных лицензий, в дополнение к лицензии AGPL-3.0, под которой
распространяется собственный код RiedChat (см. [LICENSE](./LICENSE)).

## libsignal-protocol.js

- **Расположение:** `public/js/crypto/libsignal-protocol.js`
- **Источник:** Open Whisper Systems / Signal
- **Лицензия:** GNU General Public License v3.0 (GPL-3.0)
- **Примечание:** вендорится без изменений, сгенерированная emscripten-сборка.
  Не проходит через сборку Vite - подключается как classic-`<script>` в
  `index.html`.

## Strophe.js

- **Способ подключения:** загружается во время работы приложения с CDN
  (`cdn.jsdelivr.net/npm/strophe.js`), в этом репозитории не вендорится.
- **Лицензия:** MIT License
- **Примечание:** не входит ни в исходный код, ни в сборку, производимую
  из кода этого репозитория.

## Google Fonts (Inter, IBM Plex Mono)

- **Способ подключения:** загружаются во время работы приложения с
  `fonts.googleapis.com`, в этом репозитории не вендорятся.
- **Лицензия:** SIL Open Font License 1.1 (OFL)
- **Примечание:** не входят ни в исходный код, ни в сборку.

## Vite

- **Роль:** только инструмент сборки (`devDependencies` в `package.json`).
- **Лицензия:** MIT License
- **Примечание:** не распространяется в составе приложения, используется
  только на этапе сборки для получения `dist/`.
