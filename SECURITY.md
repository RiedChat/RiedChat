# Политика безопасности

Если вы считаете, что обнаружили уязвимость в RiedChat (ошибку, позволяющую
сделать что-то, что не должно быть возможным), пожалуйста, сообщите об этом
приватно - через **<quardinimus@gmail.com>**.

Пожалуйста, не сообщайте об уязвимостях через публичные GitHub issues,
discussions или другие открытые каналы - это даёт нам время выпустить
исправление до того, как риск станет известен всем пользователям.

В репорте укажите:

- Описание уязвимости и её потенциальное влияние.
- Шаги для воспроизведения, включая proof-of-concept код, если есть.
- Версию/коммит RiedChat, на котором проверялась уязвимость.

## Периметр (Scope)

«Уязвимость в RiedChat» - это уязвимость в коде, распространяемом через
этот репозиторий. Сюда входят, например, ошибки в реализации OMEMO-
шифрования сообщений в коде этого проекта, утечки в сигналинге звонков
(WebRTC), XSS/инъекции в UI.

Не входит в периметр и должно репортиться отдельно:

- Уязвимости в самой библиотеке `libsignal-protocol.js` как таковой -
  сообщайте апстриму (Signal/OWS), не в этот репозиторий.
- Проблемы конкретного развёртывания (неправильно настроенный XMPP-сервер,
  TURN-эндпоинт, слабые TLS-настройки на стороне сервера) - сообщайте
  оператору этого конкретного развёртывания, не разработчикам проекта.

## Поддерживаемые версии

| Версия | Поддерживается |
| ------ | --------------- |
| main   | Да              |

Проект пока не ведёт несколько стабильных релизных веток; исправления
безопасности выпускаются только для актуального кода в `main`.
