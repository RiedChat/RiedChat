# Установка

RiedChat - статический клиент (собранный `dist/`), для работы ему нужен
только XMPP-сервер с поддержкой требуемых XEP (см. список в
[SERVER_SETUP.md](./SERVER_SETUP.md#поддерживаемые-xep)). Сам сервер
RiedChat не поднимает - требования к нему и пример конфига Prosody - там же.

## Сборка клиента

```bash
npm install
npm run build     # прод-сборка в dist/
npm run preview   # локальный просмотр dist/
```

`dist/` - обычная статика: разложите её на любом веб-сервере (Nginx, Apache,
Caddy и т.п.), раздающем HTTPS. Отдельного бэкенда, кроме XMPP-сервера, не
требуется.

## Как клиент находит XMPP-сервер

Домен/адрес WebSocket-эндпоинта пользователь вводит на экране логина
(`ui/login-screen.js`); последний использованный адрес запоминается в
`localStorage` под ключом `riedchatLastWsUrl` для автозаполнения при
следующем входе. Отдельного конфиг-файла на этапе сборки задавать не нужно.

## Разработка

Остальные npm-скрипты (dev-сервер, тесты, lint, format) - в
[package.json](../package.json). Флаг `?debug=1` в адресной строке включает
отладочную панель (`src/core/env.js`).
